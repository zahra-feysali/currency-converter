# Currency Converter

A simple, responsive currency converter built with **React**, **TypeScript**, and **CSS**.

🔗 **Live Demo:** [View Demo](https://zahra-feysali.github.io/currency-converter/)

## Features

- Convert USD to IRR and IRR to USD.
- Manually enter the amount and exchange rate.
- Display formatted results using Persian numerals.
- Validate inputs and display error messages.
- Responsive design with Persian typography.

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/zahra-feysali/currency-converter.git
cd currency-converter
npm install
npm run dev
```

Open the local URL provided by Vite to view the application.

## Conversion Formulas

- **USD to IRR:** Amount × Exchange Rate
- **IRR to USD:** Amount ÷ Exchange Rate

The exchange rate is entered manually. No external API is used to fetch live rates.

## Font

The application uses the [Vazirmatn](https://github.com/rastikerdar/vazirmatn) font for Persian typography.
